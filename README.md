# Final Front

Proyecto realizado para el examen final de Programación de Interfaces Web.

## Tecnologías utilizadas

- Next.js
- React
- TypeScript
- CSS
- Axios
- Rick and Morty API

## Funcionalidades

- Listado de personajes de Rick and Morty.
- Filtro por estado.
- Filtro por género.
- Filtro por nombre.
- Paginación.
- Página dinámica de detalle de personaje.

## Instalación

Para instalar las dependencias:

npm install
npm run dev
